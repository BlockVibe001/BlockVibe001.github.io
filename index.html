03 / 更新日志

每次更新，
都写清楚。

手机版与电脑版分开记录，只写真正发生的变化。完整历史在 GitHub Releases 和官网更新日志里。

v1.0.76NEW2026-11-20WINDOWS

联机中心合并

星云直连和全启动器兼容入口合并成一张「联机中心」：加入时粘贴星云房卡、P 开头 PCL 邀请码、U/ 陶瓦房号或 12 位 EasyTier 房间号都能自动分流；创建房间可选自动、星云直连、PCL、陶瓦、EasyTier。原有的分项参数页收进「高级设置」，不再来回切卡片。

v1.0.752026-11-20WINDOWS

跨启动器联机补齐

联机页新增「一键加入」：粘贴房间号自动识别 P 开头的 PCL2 邀请码，或 U/、4-4-4-4 的陶瓦房号。PCL CE、HMCL、FCL 走陶瓦 21 位 U/；邀请码额外带公共中继兜底，94 号节点不可达也能组网。另加「手动填 EasyTier 参数」，可直接和任意 EasyTier 系工具对接；并补上跨启动器兼容免责声明。

v1.0.742026-11-19WINDOWS

安装包补齐 PCL 与免责声明

重新打包 Windows 安装器，联机页、关于页和免责声明都进入正式包；官网下载按钮同步指向新版本。

v1.0.732026-11-19WINDOWS

跨启动器邀请码联机

新增兼容模块：生成 P 开头的 v2 邀请码，PCL2 / PCL CE 等支持公开约定的启动器可以直接粘贴加入；陶瓦房号也能直接粘贴。走内置 EasyTier，不修改陶瓦源码。

v1.0.18NEW2026-11-19ANDROID

联机大厅补齐陶瓦与账号入口

Java 联机页新增陶瓦联机卡片，可直接打开 FCL 或查看步骤；账号入口前置，离线、微软正版、第三方外置都能切换。

v1.0.172026-11-19ANDROID

联机页与图标统一

手机版联机入口补齐，统一使用新图标；下载线程上限 128，电脑版 256。能移植的电脑版功能继续往手机版搬。

v1.0.102026-11-18ANDROID

基岩版 Add-On 本地库

导入的 .mcaddon / .mcpack 会留一份在 App 私有目录，随时再次送进 Minecraft；不写 com.mojang，不碰存档。

v1.0.92026-11-18ANDROID

微软正版账号登录

设备码授权，登录后同步玩家名、头像、皮肤与披风；只读公开资料，不保存密码或令牌。

v1.0.82026-11-18ANDROID
