02 / 设计原则

为下一局，
留出安静。

没有弹窗追着你开会员，也没有把启动器做成第二个桌面。该出现的时候出现，该退后的时候退后。

01

本地配置，留在本机

账号资料、实例、下载记录与壁纸都存在这台设备，不上传到陌生服务器。

LOCAL FIRST
02

不替你决定玩什么

Java 与基岩并列，模组与 Add-On 分开说明。没有默认勾选，也没有偷偷安装。

NO NUDGE
03

更新写得清楚

每个版本改了什么、修了哪个问题，都写进更新日志，不拿“优化体验”糊过去。

HONEST LOG
04

尊重第三方作者

游戏、模组、Add-On 归各自作者所有；启动器只做入口与索引，不托管游戏安装包。
